07

公開・引き渡し

PUBLISH & HANDOVER

このアプリは1つのHTMLファイルだけで動きます。ファイルを書き出せば、GitHubとCloudflare Pagesでそのまま公開でき、あとから相手に渡すこともできます。

GitHub ＋ Cloudflare Pages で公開する手順

  1. 上のボタンで index.html を書き出す
  2. GitHubで新しいリポジトリを作り、index.html をアップロードする（相手に渡す時は、そのリポジトリの管理者として招待すれば引き継ぎ完了）
  3. Cloudflare Pages で「Connect to Git」からそのリポジトリを選び、ビルド設定は空のまま（フレームワークなし）デプロイする
  4. 公開URL（*.pages.dev）が発行される。以後の更新は GitHub にファイルを push するだけで自動反映される

動画や分析結果は利用者の端末内だけで処理・保存されるため、公開側にサーバーやデータベースは不要です。引き渡し後も、利用者のデータが移行することはありません。

これから対応予定の機能

正直にお伝えします。次の機能はまだ入っていません：背景の人の顔ぼかし、クリッカー残量のmm表示（ものさしの基準が映っていないと正確に出せないため）、3方向の動画を1射にそろえる詳細分析、左射ち対応。いま使えるのは、このページに表示されている機能だけです。

参考：フェーズ名と基本フォームの確認ポイントは、公益社団法人 全日本アーチェリー連盟「アーチェリーの射ち方」を参考にしています（archery.or.jp/start/howto.html）。ただし本アプリは、体格や意図の個人差を無視した一律の合否判定には使いません。

姿勢推定：MediaPipe Pose（ブラウザ内処理）。分析結果は目安です。痛みや違和感がある時は、無理をせず指導者や医療機関に相談してください。

サンプル体験 ・ 本物の分析ではありません

1. 方向と動画を選ぶ

最初に「どの方向から撮ったか」を選び、撮影した動画を1つ選びます。右・左の側面では足元が映っていなくても大丈夫ですが、その場合スタンス（足の位置）は「判定不可」になります。

2. フェーズ（射の区切り）を確認

1回の射は8つの区切り——スタンス→セット→セットアップ→ドローイング→アンカリング→エイミング→リリース→フォロースルー——に分かれます。AIの候補がずれていたら、ボタンで0.1秒ずつ直せます。

3. 結果は5つに分かれて出ます

観測結果（角度や時間など、見えた事実）／再現性（3射以上で、毎回そろっているか）／基準射との差（自分のお手本の1射との違い）／基本フォーム確認／判定不可（見えなかった所と、その理由）。総合点は出ません——体格も意図も人それぞれだからです。

4. グラフの見方

グラフの点をタップすると、その瞬間の数値と、骨格を重ねた静止画が出ます。「基準射」を登録しておくと、グラフに基準の線が引けて、ON／OFFもできます。準備ができたら、自分の動画で試してみてください。
